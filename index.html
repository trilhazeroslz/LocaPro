Armazenamento online no domínio

Para sincronizar entre computadores e celulares, publique também o arquivo api.php e a pasta dados no mesmo diretório do sistema. O servidor precisa ter PHP com permissão de escrita na pasta dados.
Sincronização com o servidorAinda não conectado ao armazenamento online.

Armazenamento local e backup

Os dados ficam salvos neste navegador. Para escolher uma pasta no computador e guardar cópias dos dados, use a opção abaixo. O navegador solicitará permissão para acessar a pasta.
Diretório de dadosNenhuma pasta selecionada. O sistema está usando o armazenamento local do navegador.
Exportar backupGera um arquivo JSON com orçamentos, ordens, faturamento e configurações.
Importar backupRestaura os dados de um arquivo JSON exportado pelo LocaPro.
Imprimir / salvar relatóriosUse a impressão do navegador para salvar documentos em PDF.

Sobre o sistema

LocaPro — Sistema de gestão de locação de projetores multimídia. Versão 1.0. Aplicação local, sem necessidade de servidor.
